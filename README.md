<div align="center">

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)
![Whisper](https://img.shields.io/badge/OpenAI%20Whisper-412991?style=for-the-badge&logo=openai&logoColor=white)
![RAG](https://img.shields.io/badge/RAG%20Pipeline-FF4136?style=for-the-badge)

![LLM](https://img.shields.io/badge/LLM%20Prompting-7B2FBE?style=for-the-badge)

</div>

```
🎙️ Ingestion   →  OpenAI Whisper transcription on 50+ videos
🧩 Chunking    →  2,000+ semantic segments with vector embeddings
🔍 Retrieval   →  Cosine similarity → top-5 ranked context matches
🧠 Generation  →  LLM prompting pipeline for context-driven answers
⚡ Impact      →  80% reduction in manual topic search time
```

**Key Achievements:**
- 🎙️ Deployed **OpenAI Whisper** for automated transcription across entire video library
- 🧩 Segmented content into **2,000+ semantic chunks** with indexed vector embeddings
- 🔍 Cosine similarity search delivering **top-5 ranked** relevant matches per query
- 💡 Full LLM pipeline synthesizing retrieved context into precise, accurate responses
- ⚡ **80% faster** content discovery — eliminated manual video scrubbing entirely
